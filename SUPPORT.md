# Suporte

Antes de abrir uma issue, execute:

```bash
sudo sshplus --version
sudo sshplus --status
sudo ./verify.sh
```

Não cole senhas, chaves, tokens ou o conteúdo de `/etc/slowdns/server.key`.

Para erros, use o modelo **Relatar erro**. Para propostas, use **Solicitar
melhoria**. Dúvidas específicas de hospedagem, DNS ou firewall devem incluir o
provedor e a topologia, sem revelar credenciais.
